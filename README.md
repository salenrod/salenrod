### Featured project

#### AWS Cloud Incident Response Automation Lab

Hands-on AWS security engineering lab that implements an automated incident-response pipeline around a synthetic GuardDuty-style finding.

The project covers:

* automated security triage;
* MITRE ATT&CK mapping;
* evidence preservation before containment;
* controlled EC2 quarantine;
* AWS Step Functions orchestration;
* EventBridge event ingestion;
* DynamoDB incident state and idempotency;
* CloudWatch monitoring and alerting;
* IAM least privilege;
* Infrastructure as Code with Terraform;
* automated validation and recovery procedures.

The objective is to turn security incident-response procedures into **controlled, auditable and repeatable engineering workflows**.
